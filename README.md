# daily-ranzdomizer
Google Chrome extension to randomize google meet participants  

# How to install

1. Download extension
2. In your browser, go to `chrome://extensions`
3. Activate `Developer mode`
4. Click in `Load unpacked`
5. Search the extension and load it


# How to use it

1. In the Google Meet call, open the participants panel.
2. Click on the extension icon. You will see a panel like this.
<img width="302" height="158" alt="image" src="https://github.com/user-attachments/assets/8cd84fc9-87bd-46f6-a42b-e01c568519a8" />

3. Click on "Randomize participants."

<img width="302" height="376" alt="image" src="https://github.com/user-attachments/assets/586f1ea8-614d-4f8a-82f4-030d048928b5" />

4. Now you can start the daily with the "Start daily" button and move from one participant to another, using the arrows, when it's their turn to speak.
